# Roadmap

## 0.1 foundation

- Provider-neutral .NET 8 contracts and explicitly configured provider routing.
- Read-only, scoped sales questions and structured queries.
- Gemini, OpenAI, Hugging Face and compatible endpoint adapters.
- Synthetic business connector, console demo and authenticated API.
- Deterministic analytics and security/provider/accuracy tests.

## Next priorities

1. Validate live model/account combinations and publish a tested compatibility matrix.
2. Package stable NuGet releases and replace development project references in product integrations.
3. Add production identity integrations with tenant-specific audit retention.
4. Add generic SQLite connector using a documented synthetic schema.
5. Add MySQL/PostgreSQL/REST connector examples with least-privilege access.
6. Expand bounded natural-language coverage and ambiguity detection using an evaluation corpus.
7. Extend row-level PII policies and configurable field classification.
8. Add comparable-period definitions and statistical forecasting behind separate interfaces.
9. Add optional streaming, structured model planners and validated tool execution when supported.
10. Expand load tests, cancellation guarantees and opt-in host circuit breakers.

Managed hosting, enterprise connectors and proprietary commercial analytics may be separate products. Proprietary financial scoring and regulated credit decisions are outside this open core.
